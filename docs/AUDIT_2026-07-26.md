## Depth Ladder

### certificate-bound-dynasty-chronicle

- **L1** — Reject claimed clan/outcome fields and require the actor to belong to the requested clan.
- **L2** — Accept only gameId, derive clan/outcomes from an archived result certificate, and deduplicate clan/game writes.
- **L3** — Extract the router, create canonical request/response receipts, persist a certificate- and evidence-bound event exactly once, expose structured provenance, wire the post-match caller, and ratchet route/composition policy.

### certified-tournament-result-spine

- **L1** — Require a gameId and derive the winner from a verified archived certificate.
- **L2** — Bind exact participants/map, persist game and certificate identity, and reject duplicate game reuse.
- **L3** — Extract router and pure authority seams, add transactional/idempotent persistence and hydration, enforce route policy, and cover adversarial plus concurrent advancement.

### transaction-decoupled-leaderboard-projection

- **L1** — Move the cache rebuild after COMMIT so cache failure cannot roll back progression.
- **L2** — Replace the cache with an indexed deterministic top-N projection and add parity tests.
- **L3** — Ship a versioned projection contract with stable tie order, source/freshness metadata, migration-safe retirement, concurrent-write tests, and direct query-shape assertions.

### certified-rivalry-revenge-projection

- **L1** — Put the revenge counter in deterministic match stats and render it directly.
- **L2** — Track opponent identity and prove only a counter-intercept against the same rival increments.
- **L3** — Bind the metric through simulation, schema, quorum certificate, recap, telemetry, and adversarial tests while deleting browser authority.
